## Using this repo

Copy `Assets/_Project` into a Unity 6 URP project with Cinemachine 3 and the Input System installed.
Set Active Input Handling to "Input System Package (New)" and add a `Player` layer.

## Controls

WASD move, mouse look, Shift sprint, Left Alt walk, Space jump or vault, C crouch, right mouse aim.
Test keys: H damage, J armor, K knockdown, R revive.

## Assets

Original assets only. Characters and animations from Mixamo. No real brands.
